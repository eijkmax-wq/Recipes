# Mijn Recepten

Persoonlijke recepten-app voor op de telefoon. Statische site, gehost op GitHub Pages.

- **Filters:** zoeken, tijd, tags, en "met wat ik heb" (alles in huis / mist max 1 of 2).
- **Thuis:** vink aan wat je in huis hebt; recepten sorteren zich op wat je mist.
- **Slimme suggesties:** bovenaan 3 voorstellen, op basis van 👍/👎, hoe lang geleden je iets maakte en wat je in huis hebt.

Recepten toevoegen: stuur in Claude Code een screenshot met `/recept` of "voeg dit recept toe". Zie `CLAUDE.md`.

Lokaal bekijken: `python3 -m http.server` en open http://localhost:8000.
