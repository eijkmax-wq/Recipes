# Mijn Recepten

Persoonlijke recepten-app voor op de telefoon. Statische site, gehost op GitHub Pages.

- **Filters:** zoeken, tijd en vega.
- **Opmaken:** typ wat er nog ligt; je krijgt recepten die er zoveel mogelijk van gebruiken. Voorraadkast-dingen (data/voorraadkast.json) tellen niet mee.
- **Slimme suggesties:** bovenaan 3 voorstellen, op basis van 👍/👎 en hoe lang geleden je iets maakte.

Recepten toevoegen: stuur in Claude Code een screenshot met `/recept` of "voeg dit recept toe". Zie `CLAUDE.md`.

Lokaal bekijken: `python3 -m http.server` en open http://localhost:8000.
